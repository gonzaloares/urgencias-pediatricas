<div class="protocol-intro">
  <strong>Todo dolor escrotal agudo es torsión testicular hasta que pueda descartarse con seguridad.</strong> Si la sospecha clínica es alta, la exploración quirúrgica no debe retrasarse por una ecografía.
</div>

<a id="torsion"></a>
## 1. Torsión testicular

### Sugiere torsión

- comienzo brusco;
- dolor intenso;
- náuseas/vómitos;
- testículo elevado/horizontalizado;
- cordón engrosado;
- reflejo cremastérico ausente;
- ausencia de síntomas urinarios.

La viabilidad es máxima si se trata en las primeras **4–6 h**.

<div class="clinical-card clinical-card-danger">
  <strong>Si se sospecha torsión o no puede excluirse:</strong> Cirugía/Urología inmediata + ayuno + analgesia. No esperar pruebas que retrasen quirófano.
</div>

<a id="exploracion"></a>
## 2. Exploración

- inspección bilateral;
- posición testicular;
- edema/eritema;
- palpación del testículo, epidídimo y cordón;
- reflejo cremastérico;
- hernia inguinal;
- abdomen;
- genitales/uretra.

### Diagnósticos frecuentes

| Diagnóstico | Pistas |
|---|---|
| **Torsión testicular** | Dolor brusco, vómitos, testículo alto/horizontal, cremastérico ausente |
| **Torsión apéndice** | Dolor focal polo superior, posible “punto azul”, menos afectación general |
| **Epididimitis** | Dolor posterolateral, disuria/fiebre posibles |
| **Hernia incarcerada** | Masa inguinoescrotal irreductible, vómitos |
| **Trauma** | Antecedente traumático, hematoma |

<a id="escalas"></a>
## 3. Escalas de riesgo: TWIST y TEST

Las escalas **TWIST** y **TEST** pueden utilizarse como apoyo para estimar la probabilidad de torsión testicular y orientar la conducta inicial.

<div class="clinical-card clinical-card-warning">
  <strong>Importante:</strong> estas escalas no sustituyen la valoración clínica ni quirúrgica. Si la sospecha de torsión testicular es alta, la valoración por Cirugía/Urología debe ser inmediata y no debe retrasarse por la puntuación ni por una ecografía Doppler.
</div>

### TWIST

<div class="score-table" markdown="1">

| Criterio | Puntos |
|---|---:|
| **Induración testicular** | **2** |
| **Elevación testicular** | **1** |
| **Ausencia de reflejo cremastérico** | **1** |
| **Aumento de volumen testicular** | **2** |
| **Náuseas y/o vómitos** | **1** |
| **Puntuación total** | **7** |

</div>

**Interpretación TWIST**

<div class="score-table" markdown="1">

| Puntuación | Conducta |
|---:|---|
| **0–2** | **Riesgo bajo:** observación y reevaluación clínica |
| **3–4** | **Riesgo intermedio:** ecografía Doppler |
| **5–7** | **Riesgo alto:** valoración quirúrgica urgente |

</div>

### TEST

<div class="score-table" markdown="1">

| Criterio | Puntos |
|---|---:|
| **Induración testicular** | **2** |
| **Elevación testicular** | **2** |
| **Ausencia de reflejo cremastérico** | **1** |
| **Aumento de volumen testicular** | **1** |
| **Náuseas y/o vómitos** | **2** |
| **Edad ≤1 año o ≥10 años** | **2** |
| **Duración del dolor <6 horas** | **1** |
| **Puntuación total** | **11** |

</div>

**Interpretación TEST**

<div class="score-table" markdown="1">

| Puntuación | Conducta |
|---:|---|
| **0–3** | **Riesgo bajo:** observación y reevaluación clínica |
| **4–7** | **Riesgo intermedio:** ecografía Doppler |
| **8–11** | **Riesgo alto:** valoración quirúrgica urgente |

</div>

<div class="clinical-card clinical-card-note">
  <strong>Aplicación práctica:</strong> las escalas son especialmente útiles para ordenar el riesgo cuando la presentación no es concluyente. Una puntuación baja no debe utilizarse de forma aislada para descartar torsión si la historia o la exploración son sugestivas.
</div>

<a id="eco"></a>
## 4. ¿Cuándo hacer ecografía Doppler?

### No debe retrasar cirugía

Si la clínica es altamente sugestiva de torsión.

### Puede ayudar

Después de valoración quirúrgica si:

- sospecha intermedia;
- diagnóstico incierto;
- se puede realizar de forma inmediata sin retrasar tratamiento.

<div class="clinical-card clinical-card-warning">
  <strong>Una ecografía negativa no excluye al 100% la torsión</strong> si la clínica es muy sugestiva.
</div>

<a id="apendice"></a>
## 5. Torsión de apéndice testicular

Más frecuente en prepuberales.

- dolor más localizado;
- reflejo cremastérico conservado;
- testículo en posición normal;
- “blue dot sign” ocasional.

Una vez excluida torsión testicular:

- reposo;
- AINE/paracetamol;
- soporte escrotal.

Suele resolver en **5–10 días**.

<a id="epididimitis"></a>
## 6. Epididimitis / epididimo-orquitis

Valorar:

- fiebre;
- disuria;
- secreción uretral;
- instrumentación urinaria;
- malformación urinaria;
- actividad sexual en adolescente.

### Pruebas

- orina + urocultivo;
- PCR para gonococo/chlamydia si riesgo de ITS;
- ecografía si diagnóstico incierto después de excluir torsión.

### Antibiótico

No toda epididimitis prepuberal necesita antibiótico.

Tratar si:

- ITU documentada/probable;
- anomalía urinaria;
- lactante pequeño;
- ITS;
- cuadro bacteriano sistémico.

Segundo episodio → valorar estudio de vía urinaria/Urología.

<a id="hernia"></a>
## 7. Hernia inguinal incarcerada

- masa dolorosa irreductible;
- irritabilidad;
- vómitos;
- puede extenderse al escroto.

→ valoración quirúrgica urgente.

Si no se reduce o existen signos de compromiso intestinal/testicular → cirugía.

<a id="trauma"></a>
## 8. Trauma testicular

Valorar:

- integridad del testículo;
- hematoma;
- hematocele;
- ruptura.

Ecografía Doppler suele ser útil.

Consulta quirúrgica si:

- dolor/tumefacción importantes;
- testículo no se palpa bien;
- hematocele;
- sospecha de rotura.

En lactante o mecanismo incongruente considerar maltrato.

### Detorsión manual

Si existe demora inevitable hasta quirófano, un profesional experimentado puede intentar detorsión manual como medida temporal.

- habitualmente rotación hacia fuera (“abrir un libro”);
- detener si aumenta dolor;
- puede requerir más de 180°;
- **nunca sustituye la exploración/fijación quirúrgica bilateral**.

<a id="no-hacer"></a>
## 9. No hacer

- No retrasar Cirugía por pedir ecografía si la torsión es probable.
- No tranquilizarse solo porque exista flujo Doppler si la clínica es muy sugestiva.
- No atribuir a epididimitis un dolor brusco con vómitos sin excluir torsión.
- No dar antibiótico a toda epididimitis prepuberal sin datos bacterianos.
- No dar el alta si no se ha excluido razonablemente torsión testicular.
