<div class="protocol-intro" markdown="1">

**Intervalos pediátricos orientativos para urgencias, desde el nacimiento hasta los 17 años.** El intervalo de referencia de la **analítica procesada en el hospital tiene prioridad**: los resultados dependen de la edad, el sexo, el equipo, el método y el tipo de muestra. Los intervalos de referencia **no son umbrales diagnósticos ni límites de tratamiento**.

<a id="electrolitos"></a>
## 4. Bioquímica: electrolitos, glucosa y equilibrio ácido-base

| Determinación / edad | Intervalo orientativo |
|---|---|
| **Sodio (≥1 año)** | 135–145 mmol/L |
| **Potasio (0–10 días)** | 3,5–6,0 mmol/L |
| **Potasio (>10 días)** | 3,5–5,0 mmol/L |
| **Cloro (1–17 años)** | 102–112 mmol/L |
| **Bicarbonato sérico / CO₂ total (infancia)** | 18–27 mmol/L, según laboratorio y edad |
| **Glucosa en ayunas (>1 mes)** | 65–99 mg/dL |
| **Glucosa aleatoria (≥1 año)** | 70–140 mg/dL, intervalo analítico de referencia, no umbral diagnóstico |
| **pH arterial (0–1 mes)** | 7,32–7,42 |
| **pH arterial (>1 mes)** | 7,35–7,45 |
| **pH venoso (0–1 mes)** | 7,30–7,40 |
| **pH venoso (>1 mes)** | 7,33–7,43 |

**Precauciones:** para sodio y cloro neonatales no aplicar sin más los rangos de mayores de 1 año; deben utilizarse los intervalos locales. Una muestra **hemolizada** puede elevar falsamente el potasio. La gasometría depende de la **procedencia arterial o venosa**. En el neonato, las cifras de glucosa de referencia **no sustituyen los umbrales de valoración y tratamiento de la hipoglucemia**.

<a id="creatinina"></a>
## 5. Función renal: creatinina por edad

Intervalos propuestos para **métodos enzimáticos**; dependen de masa muscular, método analítico y sexo en pubertad. Se muestran en **µmol/L**; conversión orientativa a mg/dL: dividir por 88,4.

| Edad | Creatinina (µmol/L) |
|---|---|
| 0–13 días | 27–81 |
| 14 días–<1 año | 14–34 |
| 1–<3 años | 15–31 |
| 3–<5 años | 23–37 |
| 5–<7 años | 25–42 |
| 7–<9 años | 30–48 |
| 9–<11 años | 28–57 |
| 11 años | 36–64 |
| 12 años | 36–67 |
| 13 años, varones / mujeres | 38–76 / 38–74 |
| 14 años, varones / mujeres | 40–83 / 43–75 |
| 15 años, varones / mujeres | 47–98 / 44–79 |
| 16 años, varones / mujeres | 54–99 / 48–81 |
| >16 años, varones / mujeres | 59–104 / 45–84 |

*Fuente: UK Kidney Association / Paediatric Laboratory Medicine Network (PaLMnet). La creatinina neonatal en los primeros días refleja parcialmente la función renal materna.*

### Urea / nitrógeno ureico

En niños **1–17 años**, el rango de referencia de **BUN (nitrógeno ureico)** del laboratorio Mayo es **7–20 mg/dL**, aproximadamente equivalente a **urea 15–43 mg/dL**. **No confundir BUN y urea:** no son valores numéricamente intercambiables. Para menores de 1 año, consultar el rango local.

<a id="otras-pruebas"></a>
## 6. Otros análisis habituales

| Determinación / edad | Intervalo orientativo |
|---|---|
| **Calcio total (<1 año)** | 8,7–11,0 mg/dL |
| **Calcio total (1–17 años)** | 9,3–10,6 mg/dL |
| **Fósforo (0–11 meses)** | 4,2–9,0 mg/dL |
| **Fósforo (1–15 años)** | 3,2–6,3 mg/dL |
| **Fósforo (≥16 años)** | 2,7–4,5 mg/dL |
| **Albúmina (≥1 año)** | 3,5–5,0 g/dL |

Los rangos de **calcio total** se deben interpretar con la albúmina; en situaciones críticas puede ser preferible medir **calcio ionizado**. La **fosfatasa alcalina** cambia de forma importante durante el crecimiento puberal. Para transaminasas, bilirrubina neonatal, PCR, procalcitonina, lactato, magnesio y coagulación, **consultar los intervalos específicos del laboratorio y el protocolo correspondiente** en lugar de asumir un único valor normal.

## 7. Cómo utilizar las tablas

- Comparar **edad exacta**, sexo cuando corresponda, **unidad** y tipo de muestra.
- Priorizar el **rango informado por el laboratorio que ha realizado el análisis**.
- Distinguir un **intervalo estadístico de referencia** de un **punto de corte diagnóstico o terapéutico**.
- Ante un resultado inesperado: revisar hemólisis, contaminación de vía, extracción capilar y repetición si procede.
- Para prematuros, recién nacidos durante la transición posnatal o pacientes con enfermedades crónicas, utilizar referencias específicas.
