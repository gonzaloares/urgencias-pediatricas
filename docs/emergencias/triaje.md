<div class="protocol-intro">
  <strong>El triaje prioriza según gravedad y riesgo, no establece un diagnóstico.</strong> Debe identificar de forma rápida al paciente que necesita intervención inmediata y ordenar la atención del resto según prioridad clínica.
</div>

<a id="objetivo"></a>
## 1. Objetivo

- Detectar situaciones de riesgo vital.
- Asignar una prioridad reproducible mediante un sistema estructurado de **5 niveles**.
- Iniciar actuaciones no demorables cuando estén protocolizadas.
- Identificar cambios clínicos durante la espera mediante **retriaje**.

### Principios

- **Triaje primero:** debe realizarse antes de procesos administrativos que puedan retrasarlo.
- Evaluación breve, dirigida y dinámica.
- No depende del orden de llegada.
- La prioridad puede cambiar en cualquier momento.

<a id="tep"></a>
## 2. Primera impresión: TEP

Realizar el **Triángulo de Evaluación Pediátrica** en segundos:

| Componente | Valorar |
|---|---|
| **Apariencia** | Tono, interacción, consolabilidad, mirada, habla/llanto |
| **Respiración** | Trabajo respiratorio, ruidos audibles, posición, retracciones |
| **Circulación cutánea** | Palidez, moteado, cianosis |

<div class="clinical-card clinical-card-danger">
  <strong>TEP alterado:</strong> priorizar valoración inmediata o muy urgente según el grado de compromiso. Si existe riesgo vital, trasladar directamente a sala de estabilización y comenzar ABCDE.
</div>

<a id="niveles"></a>
## 3. Cinco niveles de prioridad

<div class="dose-table-wrap" markdown="1">

| Nivel | Prioridad | Referencia práctica de atención |
|---|---|---:|
| **I** | Resucitación · riesgo vital inmediato | **Inmediata** |
| **II** | Emergencia / muy urgente · alto riesgo o inestabilidad fisiológica | **≤15 min** |
| **III** | Urgente · riesgo potencial, estable o discretamente inestable | **≤30 min** |
| **IV** | Menos urgente | **≤60 min** |
| **V** | No urgente | **≤120 min** |

</div>

<div class="clinical-card clinical-card-note">
  Los tiempos corresponden a una referencia práctica tipo SET/MAT. Si el hospital utiliza otro sistema estructurado validado, mantener sus tiempos y discriminantes oficiales.
</div>

<a id="valoracion"></a>
## 4. Valoración dirigida en triaje

### Preguntar

- motivo principal de consulta;
- tiempo de evolución;
- mecanismo traumático si existe;
- síntomas de alarma;
- antecedentes relevantes que modifiquen el riesgo;
- tratamiento ya administrado.

### Constantes

No es necesario obtener todas las constantes a todos los pacientes. Medir las que puedan **modificar el nivel de prioridad**:

- FC;
- FR;
- SpO₂;
- TA;
- temperatura;
- glucemia capilar cuando esté indicada.

### Situaciones que modifican la prioridad

- edad, especialmente lactante pequeño;
- inmunodepresión o enfermedad crónica compleja;
- mecanismo traumático de alta energía;
- alteración significativa de constantes;
- dolor intenso;
- incapacidad del cuidador para describir una situación estable o deterioro observado durante la espera.

<a id="alarma"></a>
## 5. Situaciones de alarma

### Nivel I / valoración inmediata

- apnea o ausencia de respiración efectiva;
- obstrucción grave de vía aérea;
- insuficiencia respiratoria extrema;
- shock descompensado;
- parada cardiorrespiratoria;
- coma o ausencia de respuesta;
- convulsión activa prolongada;
- anafilaxia con compromiso respiratorio o circulatorio;
- trauma grave con inestabilidad;
- hemorragia exanguinante.

### Nivel II / muy urgente

Valorar como mínimo prioridad muy urgente ante:

- dificultad respiratoria moderada-grave;
- alteración marcada de apariencia;
- signos de shock compensado;
- dolor intenso;
- alteración neurológica aguda;
- intoxicación potencialmente grave;
- traumatismo de riesgo;
- sospecha de sepsis;
- lactante pequeño con fiebre según protocolo específico;
- situación de salud mental con riesgo inmediato para el paciente o terceros.

<a id="dolor"></a>
## 6. Dolor en triaje

- Valorar siempre la presencia e intensidad del dolor.
- Utilizar escala adaptada a la edad.
- El **dolor intenso** puede aumentar el nivel de prioridad.
- Iniciar analgesia protocolizada precoz cuando esté indicado; no esperar a la valoración médica si existe un circuito validado.

<a id="retriaje"></a>
## 7. Retriaje durante la espera

Reevaluar si:

- aparecen nuevos síntomas;
- el cuidador comunica empeoramiento;
- cambia el aspecto del niño;
- se supera el tiempo objetivo de atención;
- existe una constante previamente alterada que requiere control.

En el retriaje:

1. repetir TEP;
2. reevaluar el síntoma guía;
3. repetir las constantes relevantes;
4. modificar la prioridad si procede;
5. documentar el cambio.

<a id="no-hacer"></a>
## 8. No hacer

- No utilizar el triaje para realizar una historia clínica completa.
- No retrasar el paso a estabilización por completar constantes o registro administrativo.
- No asignar prioridad solo por el diagnóstico sospechado.
- No obtener pruebas diagnósticas de rutina desde triaje salvo circuito protocolizado.
- No mantener sin reevaluación a un paciente cuyo estado cambia durante la espera.
