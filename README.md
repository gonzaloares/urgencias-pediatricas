# urgencias-pediatricas
Protocolos prácticos de Urgencias Pediátricas

## Manual descargable

El [manual completo en PDF](https://gonzaloares.github.io/urgencias-pediatricas/manual-urgencias-pediatricas.pdf) se compila automáticamente en el despliegue de GitHub Pages, siguiendo el orden de `mkdocs.yml`. La generación incluye índice, páginas y enlaces. Las calculadoras interactivas siguen disponibles en la web; el PDF enlaza a ellas y no intenta ejecutarlas.

Cada actualización de la rama `main` que supera las comprobaciones del proyecto vuelve a publicar el PDF en la misma dirección. También puede ejecutarse manualmente desde **Actions → Deploy MkDocs to GitHub Pages → Run workflow**.
